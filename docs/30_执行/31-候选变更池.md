## 一、使用规则

1. 所有新想法先登记在这里。
2. 候选项状态仅允许：`new` / `accepted` / `rejected` / `deferred`。
3. 只有 `accepted` 项才能进入下一迭代主线。
4. 调研层文档不自动进入候选池，需先转换为可执行变更条目。
